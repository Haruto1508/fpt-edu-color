## 📖 Giới Thiệu Dự Án

**LÓNG LÁNH** là một dự án văn hóa số được phát triển nhằm mục đích **gìn giữ, tôn vinh và lan tỏa nét đẹp của tiếng lóng, phương ngữ miền Tây Nam Bộ**.

Miền Tây không chỉ đi vào lòng người qua cảnh sắc sông nước hữu tình hay những phiên chợ nổi nhộn nhịp, mà còn in đậm dấu ấn bởi cách ăn nói mộc mạc, hào sảng và đầy dí dỏm. Đằng sau mỗi câu nói cửa miệng là cả một trầm tích văn hóa dân gian phong phú.

Dự án ra đời với sứ mệnh:
> **"GIỮ CHỮ, GIỮ HỒN QUÊ"**  
> Giúp thế hệ trẻ và bạn bè khắp nơi thêm hiểu, thêm yêu và tự hào về sự đa dạng, giàu đẹp của tiếng Việt nói chung và phương ngữ miền Tây nói riêng.

## ✨ Tính Năng Nổi Bật

- 🏠 **Trang chủ sống động**:
  - Giao diện phong cách **Neobrutalism** độc đáo, bắt mắt với hiệu ứng đổ bóng dày, màu sắc tương phản cao (vàng lúa, đỏ phù sa, xanh sông nước).
  - Mục **"Đang rần rần"** hiển thị những từ lóng được cộng đồng yêu thích và sử dụng nhiều nhất.
- 🔍 **Trang Khám Phá (Explore)**:
  - Thanh tìm kiếm thông minh với gợi ý từ vựng (Autocomplete dropdown) tức thì.
  - Bộ lọc danh mục linh hoạt: *Tất cả, Đời sống, Con người, Cảm xúc, Hành động, Tính cách...*
  - Card từ vựng thiết kế đồ họa sinh động kèm hình ảnh minh họa độc quyền.
- 📚 **Từ Điển Theo Chủ Đề (Dictionary)**:
  - Phân nhóm từ ngữ khoa học theo từng chủ đề và ngữ cảnh thực tế.
  - Tính năng thu gọn / mở rộng (collapsible accordion) tiện lợi khi duyệt danh sách lớn.
- 🔊 **Trang Chi Tiết Từ Vựng (Word Detail)**:
  - **Phát âm chuẩn giọng miền Tây**: Tích hợp audio thu âm thực tế với ngữ điệu chân chất, tự nhiên.
  - Giải nghĩa chi tiết, phân tích ngữ cảnh đời sống thường nhật.
  - Các ví dụ minh họa bằng câu thoại dí dỏm thực tế.
  - Chức năng **Sao chép liên kết (Copy Link)** để chia sẻ nhanh chóng lên mạng xã hội.
  - Gợi ý ngẫu nhiên các từ lóng thú vị khác để người dùng tiếp tục khám phá.
- 📖 **Chuyện Phía Sau (Behind The Scenes)**:
  - Hành trình và dòng thời gian phát triển của tiếng lóng qua các giai đoạn (Khởi nguồn ➔ Gắn bó ➔ Gìn giữ ➔ Lan tỏa ➔ Ghi dấu ➔ Tiếp nối).
  - Giới thiệu đội ngũ tác giả thực hiện dự án.
- ⚡ **Trải Nghiệm Mượt Mà**:
  - Tích hợp hiệu ứng cuộn trang sinh động với `Framer Motion` và `ScrollReveal`.
  - Hỗ trợ đầy đủ thiết bị từ máy tính bàn, máy tính bảng đến điện thoại di động (Responsive 100%).
  - Preload hình ảnh và âm thanh giúp trải nghiệm nhanh chóng, không bị trễ.

## 🚀 Hướng Dẫn Tải Về Và Cài Đặt

### 1. Yêu Cầu Hệ Thống (Prerequisites)

Trước khi bắt đầu, hãy đảm bảo máy tính của bạn đã cài đặt:
- **Node.js**: Phiên bản `18.x` trở lên (Khuyến nghị phiên bản LTS mới nhất `20.x` hoặc `22.x`).
  - Kiểm tra phiên bản bằng lệnh: `node -v`
- **npm** (đi kèm khi cài đặt Node.js) hoặc **yarn** / **pnpm**.
- **Git** (nếu muốn clone qua dòng lệnh).

---

### 2. Tải Mã Nguồn Về Máy Tính

Bạn có thể chọn **một trong hai cách** sau để tải mã nguồn:

#### 🔹 Cách 1: Sử Dụng Git Clone (Khuyên dùng)
Mở cửa sổ dòng lệnh (Terminal / Git Bash / PowerShell / Command Prompt) và chạy:

```bash
git clone https://github.com/Haruto1508/fpt-edu-color.git
```

Sau khi clone xong, di chuyển vào thư mục dự án:
```bash
cd fpt-edu-color
```

#### 🔹 Cách 2: Tải Trực Tiếp File ZIP
1. Truy cập vào trang GitHub của dự án: [https://github.com/Haruto1508/fpt-edu-color](https://github.com/Haruto1508/fpt-edu-color).
2. Nhấn vào nút xanh **Code** > Chọn **Download ZIP**.
3. Giải nén file `.zip` vừa tải về vào thư mục bạn muốn trên máy tính.
4. Mở thư mục đã giải nén bằng VS Code hoặc phần mềm biên tập code yêu thích.

---

### 3. Cài Đặt Thư Viện Phụ Thuộc (Dependencies)

Mã nguồn ứng dụng nằm trong thư mục `long_lanh`. Bạn cần di chuyển vào thư mục này trước khi chạy lệnh:

```bash
# 1. Di chuyển vào thư mục web app
cd long_lanh

# 2. Cài đặt toàn bộ dependencies
npm install
```

> 💡 *Nếu bạn sử dụng `pnpm` hoặc `yarn`, có thể thay bằng `pnpm install` hoặc `yarn`.*

---

### 4. Khởi Chạy Môi Trường Phát Triển (Development)

Sau khi quá trình cài đặt hoàn tất, chạy lệnh sau để khởi động máy chủ thử nghiệm:

```bash
npm run dev
```

Màn hình terminal sẽ xuất hiện đường link tương tự:
```
  VITE v8.1.1  ready in 240 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

👉 Mở trình duyệt web của bạn và truy cập vào địa chỉ: **[http://localhost:5173](http://localhost:5173)** để bắt đầu trải nghiệm ứng dụng!

---

### 5. Các Lệnh Điều Khiển Thường Dùng (Scripts Reference)

| Lệnh | Ý nghĩa & Mô tả |
| :--- | :--- |
| `npm run dev` | Khởi động Local Dev Server với tính năng Hot Module Replacement (HMR). |
| `npm run build` | Đóng gói tối ưu hóa ứng dụng vào thư mục `dist/` để chuẩn bị đưa lên hosting/server. |
| `npm run preview` | Khởi chạy máy chủ nội bộ để xem trước bản build từ thư mục `dist/`. |
| `npm run lint` | Chạy bộ kiểm tra cú pháp và chất lượng mã nguồn bằng `oxlint`. |
| `node generate_real_data.cjs` | Chạy lại script tạo mới dữ liệu `words.json` khi có thay đổi danh sách từ. |

## 🌐 Hướng Dẫn Đưa Lên Môi Trường Thực Tế (Deploy)

Dự án đã được thiết lập sẵn file cấu hình [`vercel.json`](./long_lanh/vercel.json) để hỗ trợ Single Page Application (SPA Routing). Bạn có thể dễ dàng deploy lên các nền tảng miễn phí:

### Triển khai trên Vercel:
1. Đẩy mã nguồn lên tài khoản GitHub của bạn.
2. Đăng nhập vào [Vercel](https://vercel.com/) và chọn **Add New Project**.
3. Chọn Repository `fpt-edu-color`.
4. Trong mục **Root Directory**, bấm chọn chỉnh sửa và trỏ đến thư mục `long_lanh`.
5. Bấm **Deploy** và chờ Vercel hoàn tất trong khoảng 1 phút!
